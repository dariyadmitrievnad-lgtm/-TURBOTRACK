# ТурбоТрасса: Путь к финишу

Аркадная 2D гоночная игра с видом сверху, где игрок управляет автомобилем и должен пройти трассу от старта до финиша за минимальное время, избегая столкновений с препятствиями и собирая бонусы.

🎮 Особенности

- 3 уникальных уровня с возрастающей сложностью
- Разные типы трасс: асфальт и грязь
- Бонусы: ускорение и щит (невидимые для игрока)
- Препятствия: ямы (мгновенный проигрыш) и масло (потеря управления)
- Камера, следующая за автомобилем
- Система столкновений с круговой коллизией
- Меню выбора уровня и графические кнопки

🕹️ Управление

Клавиша - Действие 
 ↑ (Стрелка вверх) - Ускорение / газ 
 ↓ (Стрелка вниз) - Торможение / движение назад 
 ← (Стрелка влево) - Поворот налево 
 → (Стрелка вправо) - Поворот направо 
 R - Перезапуск текущего уровня 
 ESC - Выход в главное меню 
 Пробел / Enter - Продолжить после победы/поражения 

🎯 Уровни

Уровень 1 — Асфальтовый старт
- Простая трасса без препятствий
- Высокое сцепление с дорогой
- Нет бонусов

Уровень 2 — Опасный участок
- Препятствия: 2 ямы (проигрыш), 1 масло (занос)
- Бонусы: ускорение и щит (невидимые)
- Среднее сцепление

Уровень 3 — Деревенская трасса
- Грязевая дорога с плохим сцеплением
- Бонусы: невидимые ускорение и щит
- Нет препятствий

✨ Бонусы

 Бонус - Эффект 
 Ускорение - Увеличение максимальной скорости на 60% на 3 секунды 
 Щит - Защита от стен на 5 секунд 

⚠️ Препятствия

 Препятствие - Эффект 
 Яма - Мгновенный проигрыш (GAME OVER) 
 Масло - Потеря управления на 2 секунды 

🛠️ Технологии

- **Язык программирования**: C++
- **Графическая библиотека**: SFML 2.6
- **Среда разработки**: Visual Studio 2022
- **Тип приложения**: Десктопная 2D игра
